# 维护与生成

根目录的 `manuel-zh.html` 是当前整理过、可直接使用的成品，包含历次人工修订。`source/` 保存撰写模块、题库、翻译、生成脚本与复习重点数据。

## 安装生成工具

在项目根目录运行：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

直接阅读 HTML 或导入 `.apkg` 不需要安装这些依赖。运行上游 Exam’1 模拟程序需要另行安装 `source/Exam1/requirements.txt` 中的依赖。

## 检查成品

```bash
.venv/bin/python tools/verify_project.py
```

检查覆盖章节总结、每节题库关联及默认展开状态、原题图、选项、快捷键脚本、锚点、词表与 Anki 包完整性。

## 生成草稿

建议先输出至临时文件，与当前成品比较后再决定是否替换：

```bash
.venv/bin/python source/gen_manuel.py --output /tmp/radioamateur-draft.html
```

每节词汇维护在 `source/lesson_vocab.json`，由 `source/lesson_vocab.py` 插入到本节考点之后；修改词汇后需同步更新成品教材。生成器会应用 `source/study_guide.json` 的考点总结与 `source/study_polish.py` 的精简、异色强调规则。`source/manual_quiz.py` 从 `decks/` 中的现有卡包读取译文与解析，从 `source/Exam1/questions/` 读取图片并嵌入 HTML。`source/all_lesson_questions.py` 按章节锚点补充其余关联题目，默认折叠。

历次人工公式校订还保存在成品与 `archive/formula-patches/`。基础生成结果不能自动视为与人工修订后的成品逐字一致，因此不要未经比较就覆盖当前教材。

## 重建卡组与词表

```bash
.venv/bin/python source/gen_deck_exam.py
.venv/bin/python source/gen_deck_kp.py
.venv/bin/python source/gen_deck_i18n.py
.venv/bin/python source/gen_vocab.py
```

卡组输出到 `decks/`，词表输出到 `data/vocabulaire.csv`。卡组脚本默认嵌入根目录当前教材，也可用 `MANUEL_OVERRIDE` 指定其他 HTML。

## 数据与归档

- `source/translations_*.json`、`source/full/`：题干、答案、注释译文。
- `source/explain/`：原理讲解与历史修订记录。
- `source/opt/`：选项译文。
- `source/kp/`、`source/kp_list.json`：知识卡内容。
- `source/q_vocab.json`：按题关联的词汇。
- `source/plan.json`、`source/work/`：章节计划与中间材料。
- `archive/`：历史教材、公式补丁、旧结构基线与旧工具。

上游软件保留为普通文件副本，上传时不包含其嵌套 `.git` 元数据。应用配置、缓存、虚拟环境与临时 Anki 媒体副本由 `.gitignore` 排除。

## 题源词汇与知识速记卡

`source/build_learning_vocab.py` 从题干、选项、既有词表与 `q_vocab.json` 生成 `question_vocab.json`（各节词汇及来源题号）和 `alphabetical_vocab.json`（字母序总词表，含动词变位）。词库更新后先运行该脚本，再生成草稿。

`source/chapter_memory.json` 维护 18 章的流程与核心规则。`source/learning_supplements.py` 保留当前正文中的公式和易错提示，并从已发布卡组读取每道关联题的解释，生成章节速记卡与附录 H。速记卡覆盖的是教材已有章节关联的 2688 道题；另 4 道无章节关联题不计入覆盖。法规沿用本教材及现有题库口径，逐题依据保留题库本身的历史条件。
