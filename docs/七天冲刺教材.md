# 法国业余无线电考试：七天冲刺教材

适用起点：法规 10/20，技术 12/20。目标：两科模拟均稳定达到 15/20 以上。你已持中国 A 类操作证，特别注意法国规则与法语题意。题库题量不是官方考试的出题比例；法规数字以现行官方文件为准。

## 怎样使用

每天约 2 小时：20 分钟复习旧错题，50 分钟学习当天内容，40 分钟做对应题，10 分钟记录错因。时间不足时先做题和复盘。法规暂时分配约 60% 的复习时间；如果某次技术成绩更低，就调整比例。所有练习题只选一个答案，先独立完成再看答案。

| 1 | 做一套限时模拟；学习 Q 简语和拼读 | 把法规错题归为知识、法语、粗心三类 |

## 一、法规：优先拿下的分数

### 1. Q 简语：看清问号

Q 码后有问号表示提问，无问号通常表示答复或通知。考试中要按题目语境和正式定义作答。

| Q 码 | 核心意思 | 记忆对照 |
|---|---|---|
| QRG | 准确频率 | fréquence exacte |
| QRK | 信号可懂度 | intelligibilité |
| QRM | 受到干扰 | brouillage |
| QRN | 受到天电等噪声干扰 | parasites |
| QRO / QRP | 增大 / 减小功率 | augmenter / diminuer |
| QRT | 停止发射 | cesser la transmission |
| QRV | 准备好 | prêt |
| QRZ | 谁在呼叫我？ | par qui suis-je appelé ? |
| QSA | 信号强度 | force des signaux |
| QSB | 信号强度起伏 | variation |
| QSL | 收妥确认 | accusé de réception |
| QSO | 通信、联络 | communiquer |
| QSY | 换到另一频率 | autre fréquence |
| QTH | 位置 | position |
| QTR | 准确时间 | heure exacte |

例如 QRO? 是“我要增大功率吗？”，QRO 是“请增大功率”。这只是高频速记，完整的 22 个 Q 码见 [原教材 R32a](../manuel-zh.html#R32a)。

### 2. 国际字母解释法

A Alfa · B Bravo · C Charlie · D Delta · E Echo · F Foxtrot · G Golf · H Hotel · I India · J Juliett · K Kilo · L Lima · M Mike · N November · O Oscar · P Papa · Q Quebec · R Romeo · S Sierra · T Tango · U Uniform · V Victor · W Whiskey · X X-ray · Y Yankee · Z Zulu（法语材料也写 Zoulou）。

易错：Alfa 无 h；Juliett 双 t。例：F4ABC → Foxtrot 4 Alfa Bravo Charlie。做题逐字母核对，不凭整体印象。

### 3. 发射类别：三位分别看

第一位是载波调制方式；第二位是调制信号的性质；第三位是传送的信息类型。常见：A = 双边带调幅，F = 调频，J = 抑制载波的单边带；3 = 单路模拟信号，E = 电话（话音），A = 可听电报。

- **A1A**：通断键控、无调制副载波的可听电报，常见于 CW。
- **A3E**：AM 话音。
- **F3E**：FM 话音。
- **J3E**：抑制载波单边带话音。

看到“BLU”（bande latérale unique）想到单边带；“porteuse supprimée”是抑制载波。详细表见 [原教材 R12a](../manuel-zh.html#R12a)。

### 4. 法国频段和通联：用检查表记忆

频段、功率和权限不要套用中国 A 类规则。每道题按顺序找：**所在地 → 频率及单位 → 业余业务地位 → 发射功率与其他限制**。先记常用频段，再针对自己错过的边界、例外做卡片；不要把题库中的频段数量当作考试比例。

基本概念：主业务与次业务是频率分配中的不同地位；次业务应避免对主业务造成有害干扰，也不能要求免受符合规定的主业务造成的有害干扰。识别电台、先守听再发射、避免干扰、按规定记录日志都是需要复习的操作规则。

从 [原教材 R21b](../manuel-zh.html#R21b) 复习频段表和题目；涉及具体边界或功率时，核对 [ANFR 法律框架](https://www.anfr.fr/gerer/radioamateurs/cadre-juridique) 链接的现行规定。原教材有待核实标记，遇到这些条目先核对，不要强记。

## 二、技术：先确保基础题

### 1. 电压、电流、电阻与功率

- 欧姆定律：U = R × I，I = U / R，R = U / I。
- 功率：P = U × I；纯电阻电路也可用 P = I²R 或 P = U²/R。
- 单位：1 A = 1,000 mA；1 kΩ = 1,000 Ω；1 MHz = 1,000 kHz；1 µF = 1,000 nF。
- 串联电阻：R总 = R1 + R2。并联：1/R总 = 1/R1 + 1/R2；两个相同电阻并联时总阻值为其中一个的一半。

例：12 V 加在 6 Ω 电阻上，电流 12/6 = 2 A，功率 12×2 = 24 W。先写单位再计算，防止把 mA 当 A。

### 2. 波长、天线与分贝

波长 λ（米）≈ 300 / 频率 f（MHz）。例如 150 MHz 时，自由空间波长约 2 m；理想四分之一波长约 0.5 m。实际天线长度还受端部效应和周围环境影响，不能把估算值当精确制作尺寸。

功率比的分贝关系：+3 dB 约为 2 倍，−3 dB 约为 1/2，+10 dB 为 10 倍；+6 dB 约为 4 倍。例：10 W 增加约 3 dB 得约 20 W。注意功率比与电压比的公式不同。

### 3. 方向判断和模块识别

- 频率升高：电容容抗下降，电感感抗上升。
- LC 谐振：电感和电容的电抗大小相等；具体电路在谐振时阻抗高低还取决于串联还是并联结构。
- AM 改变载波振幅；FM 改变瞬时频率；SSB 发送单边带。
- 超外差接收机：射频信号与本地振荡信号混频得到中频，再经滤波、放大和解调。
- 驻波比反映传输线上匹配情况；低驻波比不单独证明天线效率高。

## 三、法语读题速查

| 法语 | 中文 | 注意 |
|---|---|---|
| sauf / ne…pas | 除了 / 不 | 常把选择方向反过来 |
| augmente / diminue | 增加 / 减少 | QRO 与 QRP 常见 |
| au maximum / au minimum | 最多 / 至少 | 比较边界时圈出 |
| fréquence / longueur d’onde | 频率 / 波长 | 二者成反比 |
| puissance / tension / courant | 功率 / 电压 / 电流 | 分别用 W、V、A |
| brouillage / parasites | 干扰 / 噪声 | 注意题干具体措辞 |
| porteuse / bande latérale | 载波 / 边带 | 发射类别常见 |
| primaire / secondaire | 主业务 / 次业务 | 看对象和地区 |

先读问题最后一句，圈出否定词、单位、地区；再排除明显错误的选项。不要因为认识某个熟词就忽略整句。

## 四、自测：先完成再核对

1. “Dois-je diminuer la puissance d’émission ?” 对应：A QRO?　B QRP?　C QSY?　D QTH?
2. QRZ? 的意思是：A 谁在呼叫我？　B 现在几点？　C 频率是多少？　D 我准备好了吗？
3. QSL 的核心意思是：A 增加功率　B 信号衰落　C 收妥确认　D 停止发射。
4. 字母 J 的国际解释词是：A Juliett　B Juliet　C January　D Jazz。
5. F3E 通常表示：A AM 话音　B FM 话音　C CW　D 单边带话音。
6. J3E 中 J 表示：A 调频　B 抑制载波单边带　C 调相　D 未调制载波。
7. 题干中的 sauf 表示：A 至少　B 最多　C 除了　D 始终。
8. 频率题中最应核对的一组条件是：A 设备颜色与品牌　B 地区、频率及使用条件　C 操作员年龄与天气　D 天线颜色。
9. 12 V 加在 4 Ω 电阻上，电流为：A 0.33 A　B 3 A　C 8 A　D 48 A。
10. 通过电阻的电流 2 A，电压 12 V，功率为：A 6 W　B 14 W　C 24 W　D 48 W。
11. 两个 100 Ω 电阻并联，总电阻为：A 50 Ω　B 100 Ω　C 200 Ω　D 10,000 Ω。
12. 1 MHz 等于：A 10 kHz　B 100 kHz　C 1,000 kHz　D 1,000,000 kHz。
13. 150 MHz 的自由空间波长约为：A 0.2 m　B 2 m　C 20 m　D 150 m。
14. 10 W 功率增加约 3 dB 后为：A 5 W　B 13 W　C 20 W　D 100 W。
15. 频率升高时，理想电容容抗：A 上升　B 下降　C 不变　D 一定为零。
16. 超外差接收机的混频器产生：A 中频信号　B 电池电压　C 直流电阻　D 天线长度。

### 答案与解释

1 B：diminuer 是减小，QRP 对应降低功率。2 A：QRZ? 问谁在呼叫。3 C：QSL 表示确认收妥。4 A：Juliett 双 t。5 B：F 调频，3 模拟，E 话音。6 B：J 为抑制载波单边带。7 C：sauf 是“除了”。8 B：规则取决于所在地、频率和相关条件。

9 B：I = 12/4 = 3 A。10 C：P = 12×2 = 24 W。11 A：相同电阻并联，阻值减半。12 C：1 MHz = 1,000 kHz。13 B：300/150 = 2 m。14 C：+3 dB 约为功率两倍。15 B：容抗与频率成反比。16 A：射频与本振混频得到中频。

## 五、考试前的最后检查

法规与技术各 20 题，每科各需至少 10/20；法规 15 分钟，技术 30 分钟。答错不倒扣，所有题都作答。正式考试按准考通知和考场说明执行。带准考通知和身份证件。可在 [ANFR 界面演示](https://www.anfr.fr/gerer/radioamateurs/presentation-des-epreuves-dexamen) 熟悉操作；演示题量有限，不代表完整考试范围。

错题记录模板：日期｜科目｜主题｜错因（知识/法语/计算/粗心）｜正确理由｜明天重做结果。
