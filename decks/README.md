# Anki 卡组

建议优先使用以下四份：

| 文件 | 用途 |
|---|---|
| 考题卡组·法规与制度（中译＋讲解）.apkg | 法规原题、选项、中译、题图与原理讲解 |
| 考题卡组·技术原理（中译＋讲解）.apkg | 技术原题、选项、中译、题图与原理讲解 |
| 知识卡组（法国特色法规）.apkg | 法国法规知识点复习 |
| 无线电词汇（中译例句＋原题图）.apkg | 词汇、中译例句与题图 |

其余四份是此前的基础版或合并版，保留用于兼容和追溯。为避免重复导入，初次使用优先选择上面列出的新版。

卡组内的教材是打包时的副本。根目录 `manuel-zh.html` 包含本项目后续对网页显示与考点总结的更新；更新网页不会自动改写已经导入 Anki 的卡片。
