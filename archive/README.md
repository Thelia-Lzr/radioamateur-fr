# 历史归档

这里保留旧版本与编辑过程，方便追溯，不作为当前使用入口。

- `backups/`：旧版教材 HTML 与旧 Anki 媒体副本。
- `formula-patches/`：公式转换和校订使用的精确替换数据。
- `baselines/`：旧版 HTML 的结构统计基线，不适用于已增加交互题目的新版。
- `legacy-tools/`：历史编辑、公式转换与检查脚本。它们保留原文，部分路径与旧目录布局绑定，不能直接用于新版。
- `notes/`：历史编辑规范。
- `file-moves.json`：本次整理的原位置、新位置和移动前 SHA-256。

当前网页入口是根目录的 `manuel-zh.html`，维护说明见 `docs/维护说明.md`。
