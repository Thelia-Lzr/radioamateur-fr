# 把 manuel-zh.html 里的公式改写成 MathJax LaTeX —— 工作规范

目标文件：`/home/thelia/Documents/radioamateur-fr/manuel-zh.html`
（备份在 `manuel-zh.html.bak`，结构基线在 `structure-baseline.json`）

任务：把这个中文教材里所有**数学公式**从「纯文本 Unicode」改写成
MathJax 可渲染的 LaTeX。**只改公式，不改散文。**

---

## 1. 交付物：一个 pairs JSON 文件

你**不要**直接编辑 `manuel-zh.html`。你要写一个 JSON 文件，形如
`pairs-<你的区块名>.json`：

```json
{
 "section": "T1 §1.4–§1.8 电阻率/色环/基尔霍夫/并串联",
 "pairs": [
  {"old": "精确的原文子串", "new": "替换后的子串", "count": 1, "note": "说明"},
  {"old": "…", "new": "…", "count": null, "note": "count=null 表示出现次数 >= 1 即可"}
 ]
}
```

规则（**违反会被工具直接拒绝**）：

* `old` 必须是 `manuel-zh.html` 里**逐字节精确**出现的子串。
* **`old` 和 `new` 都不能包含换行符**（single line）。也就是说：
  只替换单行内的片段。若某公式跨行，就拆成多个 pair，每个 pair 仍只
  覆盖一行内的片段。
* `new` 里**绝对不能出现 `$`**（MathJax 配置只认 `\( \)` 和 `\[ \]`）。
* `count` 写你确认的**精确出现次数**。同一个字符串在文中出现两次
  （例如目录条目 + 正文章节标题），就写 `count: 2`，并且 `new` 要让
  两处都合理。
* JSON 必须能被 `python3 -c "import json;json.load(open('文件'))"` 解析。
* 文件里 `\\` 是 LaTeX 的反斜杠：写 `\\(` 得到 `\(`。**推荐直接用单引号
  思维写 Python 风格**：JSON 字符串里 `"\\("` 表示 `\(`。务必先自测解析。

### 自检（必须做）

```bash
cd /home/thelia/Documents/radioamateur-fr
python3 apply_pairs.py --dry-run pairs-你的文件.json
```

全部 `ok` 才算完成。有 `FAIL` 就修正 `old` 或 `count` 后重跑，直到
`pairs failed : 0`。**不要**去掉 `--dry-run`（写文件由主 agent 统一做）。

## 2. 定界符规则

| 场合 | 写法 |
| --- | --- |
| 句子中间的短公式 | `\( … \)` |
| 独占一行、作为展示的公式 | `\[ … \]` |

* **附录 B「公式与换算速查」的表格单元格**：每个公式一律用 `\[ … \]`。
* `<div class="formula">` 里**只有公式**（没有汉字注解）→ 每一条公式用 `\[ … \]`。
* `<div class="formula">` 里**夹着汉字注解**（如「简化式：」「原文例题：」）
  → 汉字保留为普通文本，公式部分用 `\( … \)`。
* `<td>`、`<li>`、`<h3>`、`<p>` 里的公式 → `\( … \)`。

---

## 3. 符号改写规则

### 3.1 希腊字母（在公式里一律替换）

| 原 | LaTeX | 原 | LaTeX |
| --- | --- | --- | --- |
| λ | `\lambda` | Ω | `\Omega` |
| π | `\pi` | ρ | `\rho` |
| τ | `\tau` | η | `\eta` |
| μ / µ | `\mu` | θ | `\theta` |
| ε | `\varepsilon` | ω | `\omega` |
| φ | `\varphi` | Δ | `\Delta` |

同一个希腊字母**成对**出现，`\lambda` 在前、`\lambda` 在后都要写。

### 3.2 运算符

* `·`（作乘法）→ `\cdot`
* `×`（作乘法）→ `\times`
* `÷` → `\div`
* `−`（U+2212 减号）/ `–`（en dash 作减号）→ `-`
* `√(…)` / `√[…]` → `\sqrt{…}`；`√X` → `\sqrt{X}`
* `²` → `^2`，`³` → `^3`，`10⁻⁹` → `10^{-9}` 之类

### 3.3 分式（**保守**）

`A / B` → `\frac{A}{B}` **只在其确实是分式、且 A 或 B 含字母变量时**。

* `U / R` → `\frac{U}{R}` ✔
* `U² / R` → `\frac{U^2}{R}` ✔
* `1 / (2πfC)` → `\frac{1}{2\pi f C}` ✔
* `22500 / 1500` → 保持 `22500/1500` ✘（纯数值除法不改）
* `150 / f(MHz)` → `\frac{150}{f\,(\text{MHz})}` ✔
* **拿不准是不是分式的就别改**，保留 `A/B` 原样。保守优先。

### 3.4 下标、上标

* `Z_L` → `Z_L`（单字符下标可以不加花括号）
* 多字符下标要加花括号：`R_t`、`C_t`、`U_{BE}`、`U_{eff}`、`U_{max}`、
  `U_{moy}`、`U_{càc}`、`I_{cc}`、`R_c`、`n_s`、`n_p`
* 原文用 `R1`、`C2`、`U1`、`N2` 写数字下标的 → `R_1`、`C_2`、`U_1`、`N_2`
* 原文 HTML 里的 `<sub>C</sub>` → `_C`，`<sup>2</sup>` → `^2`
  （例如 `Z<sub>C</sub>` → `Z_C`）

### 3.5 单位

公式里的单位要用 `\text{}` 包住，或把单位留在 `\( … \)` 外面：

* `U(V) = R(Ω) × I(A)` → `\(U\,(\text{V}) = R\,(\Omega) \times I\,(\text{A})\)`
* `P = 5 W` → `\(P = 5\ \text{W}\)`
* `L(m) = 150 / f(MHz)` → `\(L\,(\text{m}) = \dfrac{150}{f\,(\text{MHz})}\)`

中文里的单位（如正文「一只 1500 Ω 的电阻」）保留原样，不要动。

### 3.6 小数逗号

公式内的法式小数逗号写成 `0{,}1`，避免 LaTeX 在逗号后加空格。

---

## 4. 不要碰的地方（重要）

* **`<p class="fr">…</p>` 全文（法语原文）**：一个字都不要改。
* **`<span class="fr">…</span>` 里的内容**（含 `<p class="ans">` 里的
  `<span class="fr">答案</span>`）：不要改。
* 汉字、中文标点、HTML 标签一律不动。
* **`<code>` 里不是公式的内容**不动（`questions.json`、`#R21b`、`90H0`、
  `num`、`cours`、频率段号 `7,000 - 7,200` 等等）。
* 频率、波段、日期、题号、页码等**纯数字与单位**（如 `28,500 MHz`、
  `145,500 MHz`、`2026-10-01`）不是公式，不动。
* 颜色名称、`RST` 码、Q 简语、呼号（`F5ABC`）等不是公式，不动。

## 5. 结构约束

改完之后必须仍然满足（`check_structure.py` 会核对）：

* 所有 HTML 标签开合计数不变（`<h2>`21、`<h3>`138、`<h4>`7、`<p>`2226、
  `<ul>`74、`<li>`932、`<table>`58、`<tr>`1010、`<td>`3531、`<div>`500、
  `<span>`1036、`<code>`617、`<ol>`141）
* `id=` 锚点 338 个，一个不多一个不少
* `\(` 与 `\)` 数量相等；`\[` 与 `\]` 数量相等
* 全文 `$` 个数为 0

因为 `old` 是逐字替换、且标签本身不出现在 `old`/`new` 里，
只要你不改标签文本，这些自然成立。**但不要为了改公式而新增/删除
标签**（例如不要把 `Z_L` 包成 `<i>Z_L</i>`）。

## 7. 工作方法

1. 先 `grep -n` / `sed -n` 把你负责的行区间**全部读完**，逐条列出公式。
2. 逐条写 pair。**`old` 要带足够上下文**，保证精确匹配、次数正确。
3. `python3 apply_pairs.py --dry-run pairs-你的文件.json`，跑到 0 fail。
4. 回报：pairs 文件路径、pair 条数、覆盖的公式条数、fail 数、
   以及**你拿不准、故意没改**的地方清单。
