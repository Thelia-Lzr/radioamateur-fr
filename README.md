# 法国业余无线电考试中文备考资料

根据 F6KGL / F5KFF 备考课程与 Exam’1 题库整理，面向使用中文学习法国 CEPT/HAREC 考试内容的学习者。

## 从这里开始

**[在线学习（GitHub Pages）](https://thelia-lzr.github.io/radioamateur-fr/)**

- **[完整中文教材](manuel-zh.html)**：18 个大章、126 个小节，包含各章重点、取自题目的每节必备法语词汇、126 张小节知识速记卡与 18 张章末速记卡、按字母排序的无线电词汇表、简短考点总结与 2688 道章节相关题目，默认展示 455 道例题。
- **[错题本](mistake-book.html)**：在教材中标记题目，集中重新作答。
- **[模拟考试](mock-exam.html)**：法规与技术分别组卷，按正式时限计时，提交后查看全部题目及解析。
- **[七天冲刺计划](docs/七天冲刺教材.md)**：按法规 10/20、技术 12/20 的起点安排复习。
- **[Anki 卡组](decks/README.md)**：法规、技术、法国法规知识点和词汇卡。
- **[法语词汇表](data/vocabulaire.csv)**：1069 条中法对照词汇，可导入 Anki。

下载或克隆项目后，用浏览器打开 `manuel-zh.html`。原题图片已嵌入网页；公式使用 MathJax，首次显示公式需要网络。

每个小节在正文及词汇之后、习题之前都有独立知识速记卡，包含读题与解题流程、公式变形、易错点，以及可展开的对照表和逐题解题依据。各大章末尾另保留整章速记卡，并可跳转到各小节卡片。词汇表位于附录 H，按法语字母排序，并收录进阶动词及题目语境。

## 课后题怎么用

每节默认显示少量例题；点击“展开其余相关题目”可练习本节全部关联题目。题目默认显示法语题干、四个选项和原题图；翻译、重点词汇、答案与解析默认隐藏。

| 操作 | 功能 |
|---|---|
| 鼠标点击题框 | 选中当前题目 |
| 方向键 | 平滑切换选中的题目 |
| `1–4` | 选择选项，用颜色反馈对错 |
| `C` | 切换当前题目的翻译与词汇 |
| `X` | 切换当前题目的图片 |
| `Z` | 展开或收起当前题目的答案与解析 |
| `Esc` | 退出选题 |
| 重做本题 | 恢复该题初始状态 |

教材目录位于左侧侧边栏，可通过左上角按钮展开或收起，各章可独立展开小节。点击章节标题或小节直接跳转，当前阅读章节会高亮；窄屏默认收起，选择小节后自动关闭侧栏。

点击每题下方“标记错题”加入错题本，再点击左侧侧边栏的“打开错题本”集中练习。错题本每次打开均恢复未作答状态，可手动移出已掌握题目；答对不会自动取消标记。标记保存在当前浏览器，换浏览器或清理浏览器数据不会保留。直接打开本地 HTML 时，请通过侧边栏的“打开错题本／返回教材”切换，让标记随链接同步。返回教材时会恢复离开前的章节、题目展开状态及阅读位置。

快捷键只作用于当前选中的题目，各题状态独立。正文考点词使用紫色加重；原来的核对过程已精简为必要的易错提醒。

## 模拟考试

从左侧侧边栏“错题本”下方进入模拟考试。法规为 20 题、15 分钟，技术为 20 题、30 分钟；两科分别以 10/20 及格，答错或未答不扣分。每卷按题库的 10 类知识主题各抽 2 题，覆盖法规 5 个大章或技术 13 个大章，并优先选择不同小节。该抽题方式用于保证复习覆盖，不代表正式考试的固定出题比例。

开始后持续计时，刷新或离开页面也不会暂停；重新进入会恢复答案和剩余时间，超时自动交卷。考试中仅显示法语题干、选项与原题图，可随时切换题号修改答案。提交后查看总分、用时及知识点覆盖，并按“全部／错题与未答／对题”筛选，展开中文翻译、词汇和解析，也可以逐题加入错题本。

## 维护

完整说明见 [维护说明](docs/维护说明.md)。安装依赖后可检查项目或生成教材草稿：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python tools/verify_project.py
.venv/bin/python source/gen_manuel.py --output /tmp/radioamateur-draft.html
```

当前成品包含历次人工公式与文字修订。生成草稿后应与成品比较，再决定是否替换。卡组内教材是其打包时的副本，网页更新不会自动修改已导入的卡片。
